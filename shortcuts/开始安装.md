# 四个手机入口

v0.1.1 已修正空时间导致不能导入的问题。旧记录可由新版 App 恢复，发生时间需核对。

**公开仓库中的这一目录不包含已签名的 `.shortcut` 文件**：签名文件含签名者 Apple ID 的签名验证记录，不适合公开分发，因此已从版本库排除。`unsigned` 中为可审查、可重建的源文件，不要直接导入。

要用手机入口，请用自己的 Apple 账号生成并签名（在项目根目录执行）：

```sh
python3 scripts/build-shortcuts.py
shortcuts sign --mode anyone \
  --input "shortcuts/unsigned/身体手记·随手记.shortcut" \
  --output "shortcuts/身体手记·随手记.shortcut"
# 其余三个同理：身体手记·记一餐 / 记训练 / 记身体
```

签名可能需要联网。签名版本仅面向签名者的设备，优先在同一 Apple 账号下使用；最终版的完整保存流程仍需先用一条测试记录确认，详见 `docs/验证记录.md`。

在 iPhone 的“文件”打开这四个签名后的文件，或使用 AirDrop 传到手机。安装时统一选择：

**iCloud Drive → Shortcuts → BodyJournal → inbox**

先在 Mac 应用“连接与数据”点击“建立并打开收件箱”，确保目录存在。也可在 iPhone 的“文件”中建立该目录，然后让 Mac 选择同一个收件箱。

先用“随手记”保存一句测试文字，检查 Mac 能导入后，再记录真实内容。照片、相机和文件夹权限由系统在首次使用时询问。iPhone 实机拍照和跨设备同步需在你的设备上完成验证。

每次保存为一个有唯一编号的 JSON 文件。文字和照片包含在同一文件中；只有文件保存完成才显示成功，iCloud 同步到另一端可能稍有延迟。不调用模型、不含密钥。
