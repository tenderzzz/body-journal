# 手机记录入口

v0.1.1 已修正空时间导致不能导入的问题。旧记录可由新版 App 恢复，发生时间需核对。

**公开仓库中的这一目录不包含已签名的 `.shortcut` 文件**：签名文件含签名者 Apple ID 的签名验证记录，不适合公开分发，因此已从版本库排除。`unsigned` 中为可审查、可重建的源文件，不要直接导入。

要用手机入口，请用自己的 Apple 账号生成并签名（在项目根目录执行）：

```sh
python3 scripts/build-shortcuts.py
shortcuts sign --mode anyone \
  --input "shortcuts/unsigned/身体手记·随手记.shortcut" \
  --output "shortcuts/身体手记·随手记.shortcut"
# 其他入口同理：身体手记·记一餐 / 记训练 / 记身体 / 记步数
```

签名可能需要联网。签名版本仅面向签名者的设备，优先在同一 Apple 账号下使用；最终版的完整保存流程仍需先用一条测试记录确认，详见 `docs/验证记录.md`。

在 iPhone 的“文件”打开这签名后的文件，或使用 AirDrop 传到手机。安装时统一选择：

**iCloud Drive → Shortcuts → BodyJournal → inbox**

先在 Mac 应用“连接与数据”点击“建立并打开收件箱”，确保目录存在。也可在 iPhone 的“文件”中建立该目录，然后让 Mac 选择同一个收件箱。

先用“随手记”保存一句测试文字，检查 Mac 能导入后，再记录真实内容。照片、相机和文件夹权限由系统在首次使用时询问。iPhone 实机拍照和跨设备同步需在你的设备上完成验证。

每次保存为一个有唯一编号的 JSON 文件。文字和照片包含在同一文件中；只有文件保存完成才显示成功，iCloud 同步到另一端可能稍有延迟。不调用模型、不含密钥。

## 更新记一餐和记身体

Mac 应用支持这些记录需要 v0.6.17 或更新版本。只更新记一餐时，双击同目录的 `更新记一餐.command`。同时更新两个入口时，运行 `更新记一餐和记身体.command`。签名完成后会打开 `下载/身体手记快捷指令`。打开新签名文件并替换同名旧入口，选择原来的 `BodyJournal/inbox`，再通过 iCloud 同步或 AirDrop 安装到 iPhone。

- **记一餐**选“只记文字”时，填完一次即可保存。相册和照片分享菜单支持一次记录最多 8 张，拍照也可直接记录。照片会去掉元数据并转为 JPEG，现有模型一次分析使用前 4 张。修复版顶部注释为 `记一餐 v2026.11.21.2`。
- **记身体**可单独记体脂率，也可与体重一起记，或同时记录体重、腰围和体脂率。输入百分数，例如 18.5。记录同步后，可在 Mac 的身体记录和趋势中查看。

## 按日期记步数

双击本目录的 `安装记步数.command`，会用这台 Mac 的 Apple 账号签名并打开安装页。签名文件保存到 `下载/身体手记快捷指令/身体手记·记步数.shortcut`，可 AirDrop 到 iPhone，也可在安装到 Mac 后通过快捷指令的 iCloud 同步使用。首次安装选择与 Mac 相同的收件箱。

更新已有入口时，遇到同名提示请选择替换；顶部注释应为“记步数 v2026.11.17”。该版修复填完步数后又出现两个文本框的问题。正常流程只有日期选择与一次步数输入，随后直接保存并显示结果。手机上的旧快捷指令不会因更新 Mac 应用自动替换；若保留了多个同名入口，请使用这个新版。

运行“身体手记·记步数”，选择日期，填入健康 App 中所选日期显示的总步数。过去日期自动按完整一天保存，今天自动按截至目前保存。数字范围为 0–100000，保留 0 步。记录按所选日期的自然日归档，重复记录同一日期按最新一次完整报告使用。当前快捷指令的日期按北京时间记录。

Mac 能量页的步数卡可直接点击“记步数”，或点下方某一天的柱条补记。表单中的“安装手机入口”可打开同一个安装程序。Mac 手动填写的步数优先于导入来源，可在“当天明细”调整。快捷指令保存的 JSON 会在同步后自动作本地提取。
