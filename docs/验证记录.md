# 验证记录

本文件只记录自动测试、桌面流程与打包验证；全部测试使用临时档案和合成数据，源码与测试中不包含真实健康数据。

## 自动化测试

- **76 项 node:test 数据与模型契约测试**：完整记录导入、重复导入、附件迟到、损坏图片、日期合法性与跨时区排序、UTF-8 文字编码、训练单位与组次歧义、历史笔记拆分、修改撤销与旧依据失效、模型结果与编辑竞态、营养范围与未匹配项、记忆有效期与主题、常用食物标签覆盖、餐食引用复制、检索分层、备份恢复及损坏备份拒绝、预算预留、OAuth 状态与 PKCE、流式响应中断及伪造依据拒绝等。
- **桌面流程冒烟（Playwright + Electron）**：新建记录、修改与撤销、导入历史笔记、趋势统计、记忆添加、常用食物添加、重启后保留、渲染层无法访问 Node、五个页面截图。
- **构建**：`tsc --noEmit`、Vite 生产构建、esbuild 主进程打包均通过。

## 版本摘要

- **v0.1**：本地档案、四类记录、iCloud 收件箱导入、修订/撤销/软删除、可读导出与完整备份；四个手机快捷指令源文件。
- **v0.1.1–v0.1.5**：空时间记录恢复、附件迟到重试、营养汇总、日期归档、首页日历、自动训练参照与重复餐食模板。
- **v0.1.6–v0.1.7**：训练组次解析、记忆回执与撤销、动作别名与手动归类；保存通路白名单修复。
- **v0.1.8–v0.1.10**：桌面桥接白名单覆盖、动作计重口径统一与动作合并、历史迁移幂等；哑铃肩推默认按坐姿统计。
- **v0.1.11**：动作按胸/背/肩/腿/核心分区显示。
- **v0.1.12**：常用食物与补剂标签（本地强制复用）、餐食引用复制、短期记忆检索与状态续期。
- **v0.1.13–v0.1.14**：反复出现食材的候选卡片、品牌匹配；一键整理记忆、失效项清理与训练参照折叠。
- **v0.1.15**：长期记忆主题键与档案分组；聊天/分析改为检索分层，周复盘独立预算。

## 构建与分发

- 目标平台：macOS Apple Silicon（arm64）；Electron + React + TypeScript，SQLite 使用 Node 内置驱动。
- 打包为本地开发签名（ad-hoc），未经 Apple Developer ID 公证，也不是 App Store 发行版。
- 仓库不包含已签名的手机快捷指令：签名文件含签名者的 Apple ID 签名验证记录，不适合公开分发；请用自己的 Apple 账号对本仓库源文件签名（见 README）。

## 仍需使用者自行验证

- 真实 ChatGPT / DeepSeek 账号授权与额度、真实餐食照片识别质量。
- iPhone 实机拍照、离线保存、跨设备 iCloud 同步。
- 自动测试使用模拟流式响应与合成记录，不消耗真实模型额度。

## 复现

```sh
npm ci
npm test
npm run build
npm run test:ui
```

`npm run test:ui` 使用临时档案与合成数据，不读写主档案。
