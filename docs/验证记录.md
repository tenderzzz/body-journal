## 构建与分发

- 目标平台：macOS Apple Silicon（arm64）；Electron + React + TypeScript，SQLite 使用 Node 内置驱动。
- 打包为本地开发签名（ad-hoc），未经 Apple Developer ID 公证，也不是 App Store 发行版。
- 仓库不包含已签名的手机快捷指令：签名文件含签名者的 Apple ID 签名验证记录，不适合公开分发；请用自己的 Apple 账号对本仓库源文件签名（见 README）。

## 仍需使用者自行验证

- 真实 ChatGPT / DeepSeek 账号授权与额度、真实餐食照片识别质量。
- iPhone 实机拍照、离线保存、跨设备 iCloud 同步。
- 自动测试使用模拟流式响应与合成记录，不消耗真实模型额度。

## 复现

```sh
npm ci
npm test
npm run build
npm run test:ui
```

`npm run test:ui` 使用临时档案与合成数据，不读写主档案。

## v0.1.16 自动更新记忆

- 首页对话：用户明确陈述的长期信息（偏好、条件、记法、补剂标签等）自动写入，不再要求出现“记住”等指令词；临时状态与待验证判断自动写入短期记忆。仍要求原话依据，数字必须出现在原话中。
- 数据分析：分析结果可附带最多 3 条长期记忆（事实或常用食物），必须满足“依据是记录原文的连续片段、名称与全部数字出现在片段中”；保存后记录详情显示“分析时自动记住”，可追溯来源。自动记忆不会被本次记录提交误标为失效。
- 78 项自动测试通过（新增对话自动记忆、分析自动补剂识别、原文依据拒绝等）。

## v0.1.17 常用食物自动记忆修复

- 修复：在首页说“加/更新/添加一个常用食物：……每100g……”，即使没有“记住”字样也应直接保存为常用食物；此前只认“记住/记下”等指令词，导致被误判为意图不明确。
- 常用食物带包装营养数字时可直接自动保存；如果给的是每100g数值，按每份100g换算。
- 79 项自动测试通过（新增“加常用食物无需记住字样”回归测试）。
- v0.1.18：进一步放宽到“带每100g/每份/每勺等标签特征的营养数据”也可自动保存，避免模型把常用食物表述为长期事实时被误拦。
