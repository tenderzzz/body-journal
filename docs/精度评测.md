# 精度评测

在「连接与数据 → 精度评测」选择自己准备的 JSON 文件，应用会在本机生成报告；也可点击「保存合成示例」取得完整格式。源码中的同一示例位于 [evaluation-example.json](../data/evaluation-example.json)。评测只计算文件里已经存在的参考和预测，不读取健康档案、不调用模型、不上传数据。示例中的食物、标签、称量值和预测均为合成数据，其结果不能证明真实识别精度。

命令行入口：

```sh
npm run evaluate -- /绝对路径/评测数据.json
```

文件根结构为 `{ "format": "bodyjournal-evaluation", "version": 1, "samples": [...] }`。可填写 `name`、`synthetic` 和 `comparison: { "baseline": "baseline", "candidate": "candidate" }`。

每条样本包含：

```json
{
  "id": "example-one-meal",
  "reference": {
    "foodIds": ["specific-product-vanilla"],
    "kcal": 120,
    "protein": 24,
    "source": "label",
    "evidence": "标签每份30g；所有示例数值为合成"
  },
  "predictions": [
    {
      "label": "candidate",
      "foodIds": ["specific-product-vanilla"],
      "kcal": { "low": 110, "high": 130 },
      "protein": 24,
      "questions": 1
    }
  ]
}
```

- `id` 在文件内唯一。同一份样本的多次分析放在 `predictions` 中；同一配置使用相同的 `label`，用于计算重复波动。
- `foodIds` 使用稳定产品编号或 FDC 编号（数字会转为字符串）。同品牌不同口味或规格应使用不同编号；评测不做名称模糊匹配。整份清单按集合比较，不能重复填写相同编号。
- `kcal` 单位为 kcal，`protein` 单位为 g；参考是单值，预测可以是单值或 `{low,high}`。应先将参考和预测换算到同一实际食用量。
- `source` 可为 `label`（包装标签）、`weighed`（称量结合明确营养数据）、`recipe`（已知配方）、`mixed` 或 `unknown`，并建议在 `evidence` 说明依据。参考本身也可能有误差，报告会列出来源分布。
- 未知的参考或缺失的预测字段直接省略，不能填写 0 代替。真实零值有效。没有营养参考的样本仍可用于观察重复波动和追问。
- `questions` 为追问数量，或问题文字数组；未知数量则省略。遗漏字段不会按零追问处理。
- 文件最多 10 MB、10,000 份样本，每份最多 30 条预测。格式错误会拒绝整份文件，不会改动健康档案。

## 如何读报告

| 指标 | 计算方式 |
| --- | --- |
| 食物清单完全匹配 | 预测与参考产品集合一致的比例 |
| 食物精确率 / 召回率 | 正确产品占预测 / 参考产品的比例；已知空清单也参与比较 |
| 热量、蛋白质绝对误差 | 预测区间中点与参考单值的绝对差 |
| 区间覆盖率 | 参考是否位于预测上下限之内，包含边界 |
| 平均区间宽度 | 上限减下限；覆盖率上升时应同时观察是否只是区间变宽 |
| 重复波动 | 同一样本、同一配置至少两次预测中点的总体标准差 |
| 追问次数 | 已提供数量的平均值 |

每个指标先在同一样本的重复分析中取平均，再对样本取平均，避免重复次数较多的样本挤占结果。指标同时列出有效样本数、有效预测次数和缺失样本数；没有可用依据时结果为 `null`。重复标准差单独按每个样本计算，再取平均。单值预测视为宽度为零的区间，只有与参考相等时才覆盖参考；食物清单均为空时完全匹配为1。

提供 `comparison` 时，差值为「候选 − 基线」，且仅比较两种配置都覆盖、相关字段也都可用的同一份样本。绝对误差负值表示下降；覆盖率、区间宽度和追问数需结合阅读，不合并成一个“准确率”。

## 建立自己的基线

先从少量常吃的包装食品、能核对分量的简单餐食开始，保留原标签、实际食用量和预测结果。照片食堂餐若没有称量或可靠配方，参考营养留空，避免把另一个估计当成真值。更新模型或提示词后，在同一批样本上记录新预测，再比较报告。不同样本、不同拍摄条件的分数不能直接作为改进证据。
