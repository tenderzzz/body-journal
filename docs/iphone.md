# iPhone 首版试用

身体手记 0.7.0 支持 iOS 16 及以上版本，可以在 iPhone 离线记录餐食、训练、身体测量、随手记和手填步数。手机原文、照片和待发变更保存在应用自己的 SQLite 档案及照片目录。Mac 可以继续使用现有的分析与食材编辑器。

## 安装与第一次配对

1. 在 Mac 打开 0.7.0 的「查看示例.command」进入隔离示例档案，或启动应用并传入 `--demo`。第一次往返请使用合成餐食和测试图片。
2. 在本仓库的 iPhone 构建运行中下载 `BodyJournal-iPhone` artifact，解压得到 `BodyJournal-iPhone.ipa` 和校验文件。在解压目录运行 `shasum -a 256 -c iphone-SHA256SUMS.txt`。IPA 面向 iPhone 真机，AltStore 在安装时用自己的账号签名。
3. 在 Mac 按 AltStore Classic 的说明安装 AltServer 并给 iPhone 安装 AltStore。在手机 AltStore 的 My Apps 页点「+」，选 IPA。后续续签和覆盖升级使用同一 Apple 账号和 App 标识，保留本机数据。请保留恢复码和本机资料，删除 App 会删除其沙盒。
4. 在 Mac 的「连接与数据 → iPhone 双向同步」点「选择空目录并创建档案」，在 iCloud Drive 新建专用文件夹，例如「身体手记同步」。展开「显示配对码 / 恢复码」，把恢复码另存到密码管理器。
5. 在手机点「同步 → 扫描 Mac 配对码」，轻点识别到的二维码，或填写恢复码。系统「文件」打开后选择同一目录。文件夹标记尚未抵达时，保持联网，稍后重选。

## 做一次餐食往返

在 iPhone 断网时点「记一餐」，输入「测试米饭一碗」，添加一张测试图，勾选「选入已配对的共享档案」及对应照片，保存。关掉应用再开，时间线上应仍有这条记录。手机联网后打开应用，晚些时候打开 Mac。两台设备都支持从同步页点「立即同步」。

在 Mac 的记录详情打开「补充 / 修正食材和分量」。已有米饭时直接修改，需要时先添加米饭。将「实际吃下的比例」改为「约一半」，点「保存并重新计算」。下次手机收到后，原记录的「已核对的分量」应显示米饭和「吃了一半」，原图还能打开。不要用重新新增一条记录来修正。

## 选择资料和处理状态

| 来源与内容 | 首版行为 |
| --- | --- |
| iPhone 或 Mac 的餐食 | 逐条预览并选入原文、类别、发生时间、时区和用户修正的食材分量。照片按原顺序逐张勾选。手机选图会校正方向、转换为 JPEG，并丢弃拍摄元数据。 |
| 训练、随手记 | 可主动选入原文和发生时间。训练截图及其他非餐食照片留在本机。选入前请核对自由文本。 |
| 身体测量、步数 | 仅存本机。iPhone 手记按记录时区凌晨四点换日，手填步数按自然日。 |
| Mac 旧快捷指令或历史记录 | 原收件箱继续按原编号导入。打开原记录详情，展开「iPhone 同步」预览并选入。重选不会重复创建；选入前的修订在 Mac 查看。 |
| 分析、对话、模型凭据、能量统计 | 继续在 Mac 使用。模型重算的修订号独立于共享记录版本。 |

- 「已存本机」表示保存成功。「待发送」表示变更已进入本机队列。「已写入共享文件夹」表示完成本机文件写入。另一端核对完整照片后写回执，发送端才显示「另一台设备已接收」。
- 照片晚到时可以先看原文。检查 iCloud Drive、剩余空间，在「文件」中下载缺少的文件，再点「立即同步」。请保留共享目录中的历史变更、照片和回执，换机恢复需要这些文件。
- 两端从同一版本编辑，或一端删除、一端编辑时，进入同步页的冲突记录。选择要保留的分量、时间和删除状态，可再编辑合并文字。保存合并版本后，两端继续同步。删除项可以在最近删除或 Mac 的已删除记录中恢复。
- 撤销目录授权后仍可本机保存。重选原目录即可补传。暂停同步会保留两端的本机副本和待发修改。恢复 Mac 完整备份会暂停同步；核对档案后再重连，应用会先读取共享目录中的后续修改。
- 共享副本使用每档案独立密钥和 AES-256-GCM。iPhone 使用本机钥匙串并排除档案目录的系统备份。Mac 用 Electron safeStorage 的系统钥匙串保护本机配对凭据。恢复码能够解密整个共享档案。Mac 数据库和完整本地备份沿用现有保护方式。新装设备需要原恢复码及完整共享目录才能恢复已选入资料。

## 构建与验收

Node 24 下运行 `npm ci`、`npm test`、`npm run build`。使用带 iPhoneOS SDK 的完整 Xcode 构建时，运行 `npm run ios:ipa`，产物位于 `release/BodyJournal-iPhone.ipa`。项目不需要 CloudKit、HealthKit entitlement 或团队签名文件。Mac 原生文件协调组件随桌面安装包一起分发。

自动化在临时档案中运行手机 SQLite、Mac HealthStore、实际 Swift 加密目录和 TypeScript 变更协议。系统「文件」选目录后重启、真实 iCloud 传播、HEIC 相册选图、AltStore 手动刷新、覆盖升级及连续七天自动续签需要在自己的设备验收。具体通过条件见[原实施计划](ios-icloud-sync-plan.md)。
