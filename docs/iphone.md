# iPhone 安装与自动同步

身体手记 0.8.0 支持 iOS 16 及以上版本，可以在 iPhone 离线记录餐食、训练、身体测量、随手记和手填步数。手机原文、照片和待发变更保存在应用自己的 SQLite 档案及照片目录。Mac 可以继续使用现有的分析与食材编辑器。

## 已经配对的用户

在原 Mac 和 iPhone 上覆盖安装 0.8.0，沿用原来的 Apple 签名、应用标识和共享文件夹。打开两端应用，保持 iPhone 在前台，首次同步会自动补齐历史。手机在「手记 → 全部记录」可翻看早期记录。「能量」可选日期查看摄入、消耗、差额、目标、营养和步数。「趋势」可切换 7 天、30 天、90 天和全部，查看身体测量、能量、步数与已完成训练。统计注明 Mac 更新时间，离线可以查看上次完整收到的结果。

以后保存即可。Mac 应用运行时会发送变更，iPhone 保存、回到前台、恢复联网和前台定时检查都会触发同步。两端无需同时在线。Mac 休眠期间手机可以继续记录，Mac 下次运行时会更新统计。「立即同步」供需要时重试。

## 第一次安装，从 AltStore Classic 开始

需要一台解锁的 iPhone（iOS 16 或更高版本）、一根能传数据的 USB 线，以及这台 Mac。两端的 iCloud Drive 使用同一个 Apple 账号。首次安装和第一次续签都可以一直插着 USB 线。

1. 在 Mac 打开官方 AltServer macOS 压缩包，解压后把 `AltServer.app` 拖入「应用程序」并打开。菜单栏出现菱形图标，即可继续。[AltServer 官方下载](https://cdn.altstore.io/file/altstore/altserver.zip)
2. 用 USB 连接 iPhone，解锁，按提示在两端点「信任」。Mac 打开访达，在侧边栏点 iPhone →「通用」，勾选「连接到 Wi-Fi 时显示此 iPhone」并点「应用」。后续同一 Wi-Fi 下可无线刷新。
3. 点击 Mac 菜单栏的 AltServer 菱形 → **Install AltStore** → 你的 iPhone。按 AltServer 的提示用自己的 Apple 账号登录。手机主屏幕出现 **AltStore** 后，打开「设置 → 通用 → VPN 与设备管理」，选自己的开发者账号并信任。再到「设置 → 隐私与安全性 → 开发者模式」打开开关，按提示重启并在解锁后确认。[AltStore 官方 Mac 安装图解](https://faq.altstore.io/altstore-classic/how-to-install-altstore-macos)
4. 将 `BodyJournal-iPhone.ipa` 放在 iPhone「文件」能看到的位置。可以用 iCloud Drive，保存安装包的地方和稍后选择的共享目录分开。保持 AltServer 运行，在 iPhone 打开 AltStore → **My Apps → 左上角 +**，选择这个 IPA，按提示使用同一 Apple 账号签名。My Apps 出现「身体手记」且点开能看到五个录入按钮，即安装成功。安装包也可从仓库 iPhone 构建运行下载。[iPhone 构建记录](https://github.com/tenderzzz/body-journal/actions/workflows/ios-package.yml)
5. Mac 首次试用在项目中双击「查看示例.command」。看到侧栏「示例档案 · 与真实数据隔离」，再进入「连接与数据 → iPhone 双向同步」。「选择空目录并创建档案」时，在 iCloud Drive 新建一个空文件夹，例如「身体手记同步试用」。点「显示配对码 / 恢复码」，用自己的密码管理器保存恢复码。
6. iPhone 打开身体手记 →「同步 → 扫描 Mac 配对码」，轻点取景框中的二维码，或填写恢复码。系统「文件」弹出时，选择第 5 步的文件夹。看到「已连接」后，把身体手记从 App 切换器划掉再打开，确认目录仍是同一个。若提示档案标记未到，先在「文件」里打开该目录并等待 iCloud 下载，再重选。

## 真机校验，按顺序操作

用一张测试图和一条带唯一文字的样例，例如「往返测试 A，米饭一碗」。Mac 示例可能已有其他条目，按这句原文统计数量。

| 步骤 | 操作 | 通过条件 |
| --- | --- | --- |
| 1 · 离线保存 | Mac 合盖。iPhone 开飞行模式并关闭 Wi-Fi →「记一餐」，填写测试文字，选一张图，勾选「选入照片 1」，点「保存到本机」。将 App 划掉再开。 | 时间线中这条样例只有一条，点开能看原文和照片。重开无需重选目录。 |
| 2 · 手机发到 Mac | iPhone 恢复网络，保持应用在前台。随后打开 Mac 示例档案，去「记录」搜索样例。 | Mac 搜到一条同名餐食，原图能打开。若暂时只见文字，等待 iCloud 下载并重试。 |
| 3 · Mac 更正，手机回读 | Mac 打开该餐 →「补充 / 修正食材和分量」。如果还没有米饭，点「添加食材」，搜索并选中「白米饭（熟）」或另一项米饭。把「实际吃下的比例」改成「约一半」，点「保存并重新计算」。回到 iPhone 打开原记录，等待前台自动更新。 | 手机「已核对的分量」显示米饭「吃了一半」，原文仍能读，原图仍在，样例数量仍为一。 |
| 4 · 手动续签 | 保持 USB 连接和 AltServer 运行，iPhone 打开 AltStore → My Apps → **Refresh All**。刷新成功后重新打开身体手记。 | AltStore 与身体手记均显示刷新成功、剩余约 7 天；样例、图片、半份修正和目录授权仍在。 |
| 5 · 一周自动续签 | 打开 AltStore 的 Background Refresh，Mac 保持 AltServer 可运行，让两台设备在这一周有机会连接相同 Wi-Fi。记下第 1 天的到期日，一周后对照新的到期日。 | 自动刷新应使到期日向后延长。记录是否需要手动干预，单次手动刷新单独计入上一步。 |

可再用第二条合成样例检查离线冲突。两端先收到同一个版本，各自断网，一端删除、另一端改文字。分别恢复联网，同步到两边都列出两个版本，选中要保留的版本并保存。再次同步后应只保留一条样例，两端显示同一结果。覆盖安装测试可在有新版 IPA 时进行，使用相同的 Apple 账号和 App 标识，并保留已有安装。

如果 AltStore 提示找不到 AltServer，保持 iPhone 解锁并改用 USB，先确认访达能看到设备。免费账号签名过期后可在 Mac 的 AltServer 菜单对同一设备覆盖安装 AltStore，再在 My Apps 里刷新身体手记；保留原 App 才能保住本机档案。[AltServer 连接与恢复](https://faq.altstore.io/altstore-classic/altserver) · [官方刷新说明](https://faq.altstore.io/altstore-classic/your-altstore)

## 选择资料和处理状态

| 来源与内容 | 自动同步范围 |
| --- | --- |
| 两端的餐食、训练、随手记 | 同步原文、类别、发生时间、时区、删除状态和人工确认的餐食分量。餐食照片可在初次保存或之后单独选择，训练截图保存在原设备。 |
| 身体测量、步数 | 同步测量值和手机手填步数。步数按自然日归属，可标明截至记录时或全天。Mac 能量页手工核对的步数随统计展示。 |
| 旧快捷指令或历史记录 | 自动补入已有的有效记录，保留原编号，重复打开应用不会多出一份。升级前已删除且从未共享的记录留在原设备的最近删除中。 |
| 能量与趋势 | Mac 按已有记录和目标计算，仅发送每日统计。最近 90 天以及更早有记录的日期可以查阅。 |
| 分析、对话与账号 | 分析原文、对话、记忆、凭据和完整数据库留在 Mac。 |

- 「已存本机」表示保存成功。「待发送」表示变更已进入本机队列。「已写入共享文件夹」表示完成本机文件写入。另一端核对完整照片后写回执，发送端才显示「另一台设备已接收」。
- 照片晚到时可以先看原文。检查 iCloud Drive、剩余空间，在「文件」中下载缺少的文件，再点「立即同步」。请保留共享目录中的历史变更、照片和回执，换机恢复需要这些文件。
- 两端从同一版本编辑，或一端删除、一端编辑时，进入同步页的冲突记录。选择要保留的分量、时间和删除状态，可再编辑合并文字。保存合并版本后，两端继续同步。删除项可以在最近删除或 Mac 的已删除记录中恢复。
- 撤销目录授权后仍可本机保存。重选原目录即可补传。暂停同步会保留两端的本机副本和待发修改。恢复 Mac 完整备份会暂停同步；核对档案后再重连，应用会先读取共享目录中的后续修改。
- 共享副本使用每档案独立密钥和 AES-256-GCM。iPhone 使用本机钥匙串并排除档案目录的系统备份。Mac 用 Electron safeStorage 的系统钥匙串保护本机配对凭据。恢复码能够解密整个共享档案。Mac 数据库和完整本地备份沿用现有保护方式。新装设备需要原恢复码及完整共享目录才能恢复已共享资料。

## 构建与验收

Node 24 下运行 `npm ci`、`npm test`、`npm run build`。使用带 iPhoneOS SDK 的完整 Xcode 构建时，运行 `npm run ios:ipa`，产物位于 `release/BodyJournal-iPhone.ipa`。项目不需要 CloudKit、HealthKit entitlement 或团队签名文件。Mac 原生文件协调组件随桌面安装包一起分发。

自动化在临时档案中运行手机 SQLite、Mac HealthStore、实际 Swift 加密目录和 TypeScript 变更协议。系统「文件」选目录后重启、真实 iCloud 传播、HEIC 相册选图、AltStore 手动刷新、覆盖升级及连续七天自动续签需要在自己的设备验收。具体通过条件见[原实施计划](ios-icloud-sync-plan.md)。
